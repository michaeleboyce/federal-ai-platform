# Adjudication Rounds — the canonical workflow

Every systematic correction to the inventory's derived data (tags, labels,
product links, lineage, ingests) runs through the same pipeline. This skill
prescribes ONE canonical shape, distilled from 10+ historical rounds
(`agentic_review`, `genai_review_2026-07`, `band_labels_2026-07`,
`product_capability_2026_07`, `omb_only_ingest`, `generic_vendor_links`,
`linkage_pass_2026-05`, `year_match_review`, ...). Historical rounds diverge
from it in places; NEW rounds should not.

## The pipeline

```
build inputs  →  label (Sonnet fan-out)  →  audit/QC (Fable)  →  apply (script)  →  gate
scripts/         verdicts_batch{N}.csv      audit_overrides     scripts/apply_*.py   checks +
build_*_inputs      closed vocab            qc_* on low-conf    idempotent, keyed    band re-
   .py                                                          by signature         baseline
```

**Model roles** (user convention): Sonnet 5 does the high-volume labeling
(one agent per batch); Fable adjudicates every verdict — either as an
explicit audit layer (`audit_overrides.csv` with agree/override/escalated +
an `AUDIT_GATE.md` declaring the round green) or by adjudicating draft
recommendations directly (as in `omb_only_ingest/ADJUDICATION.md`). QC
judges re-review 100% of low-confidence labels (`qc_input_batch*.csv` →
`qc_results_batch*.csv`). Nothing reaches the DB without the Fable pass.

## Canonical directory shape — `audit/retag/<round>/`

| File | Contract |
|---|---|
| `INSTRUCTIONS.md` | The decision rule, the CLOSED verdict vocabulary, "output EXACTLY these columns", "every input row appears exactly once", "copy the join key byte-for-byte — never invent or renumber ids". |
| `input.csv` + `input_batch{1..N}.csv` | Built by a `scripts/build_<round>_inputs.py`; batches sized for one labeler agent each. |
| `verdicts_batch{N}.csv` | Agent output. **Use this filename** (historical rounds used labels_/by_row/decisions — don't copy those). Minimum columns: join key(s), `verdict`, `confidence`, `reasoning`. |
| `audit_overrides.csv` + `AUDIT_GATE.md` | Fable audit layer (when used): per-row agree/override/escalated; the gate doc states the round is green and why. |
| `qc_input_batch*.csv` / `qc_results_batch*.csv` | Optional 100%-of-low-confidence QC layer. |
| `apply_drops.csv` | GENERATED by the apply script — rows that failed to resolve; never hand-edited. |

Verdict vocabularies are round-specific but always **closed** and validated
by the apply script (examples: `{genai,not_genai}`; `{keep,reclassify}`;
`{ingest, duplicate_of:<slug>, withheld_variant, documented_skip}`).

## Keying — never numeric ids

Ids in `use_cases`, `consolidated_use_cases`, `products` ROTATE on every
`make fix`. Durable keys only:

| Entity | Key | Resolver |
|---|---|---|
| use_cases row | `(agency_abbreviation, use_case_name)` signature | `scripts/uc_signature.py::Resolver` — `_norm` = lowercase + whitespace-collapse; fuzzy fallback same-agency `SequenceMatcher ≥ 0.92` (must beat 2nd-best); **fan-out**: one signature may hit several live rows — corrections apply to ALL; `.check(label)` exits non-zero above 2% unresolved |
| consolidated row | `slug` (deterministic) or `Resolver.cons_by_signature(agency, name)` (tolerates OMB's trailing `.`) | same module |
| product | `canonical_name` | direct lookup |
| OMB consolidated-file row | `row_hash` (stable content hash) | `omb_consolidated_rows.row_hash` |
| year lineage | `slug` on both the 2024 and 2025 sides | `apply_year_match_review._slug_index` |

If your inputs carry numeric ids anyway (legacy CSVs), re-resolve them
through the Resolver at apply time — `apply_product_gap_review.py`'s 3-tier
fallback (id → (agency, quote-substring) → (agency, name)) is the pattern.

## Apply-script contract

Every `scripts/apply_<round>.py` MUST be:

1. **Idempotent** — one of two idioms: wipe-and-reload the target table
   (band labels, product_capability_labels) or delete-by-provenance then
   re-insert (`ingest_omb_only_rows` keys on
   `omb_consolidated_source='omb_only_ingest'`;
   `persist_capability_evidence` clears its own `captured_by` rows).
2. **Batch-tolerant** — if no `verdicts_*.csv` exist yet, print a WARNING
   and `return 0` (batches land incrementally; the chain must stay green).
3. **Hard-failing on drift** — >2% unresolved keys → print the drops, write
   `apply_drops.csv`, "Refusing to apply", exit non-zero. (OMB republished /
   loader changed → re-adjudicate, don't silently skip.)
4. **Closed-vocab validating** — unknown verdict values are an error, not a
   skip.
5. **Translating confidence at the SQL boundary** — agent-facing
   high/medium/low never reaches the DB: `use_case_products.confidence` and
   `consolidated_use_case_products.confidence` are `CHECK IN
   ('strong','inferred')`; SQLite without FK pragma will silently drop
   violating rows. Reference: `apply_generic_vendor_retag.py`.
6. **Wired into the Makefile** as ONE commented line in the `fix` target,
   AFTER `auto_tag.py` (the global invariant — auto_tag wipes and re-derives
   tags each rebuild, so corrections must re-apply after it). Known ordering
   exception: `apply_genai_review.py` must precede `apply_llm_flag_drift.py`
   (the drift script keeps the last word on `is_general_llm_access=1 ⇒
   is_generative_ai=1`).

## Closing a round (all in the SAME change set)

1. Apply script wired + full `make fix` green **twice** (idempotency).
2. **Evidence persisted** where the round produced sources/quotes:
   `scripts/persist_capability_evidence.py` → `use_case_external_evidence`
   (http URL → `status='corroborated'` + `source_quote`; narrative-only →
   `'inventory_only'`; set a round-specific `captured_by`).
3. **Bands/gates re-baselined in the same commit** with the delta arithmetic
   in the test comment (e.g. "3660 = 3549 + 66 recovered + 45 ingested").
   The usual suspects: `audit/checks/check_llm_flags.py` (general-LLM
   559±50 / 789±50, agentic 66±10 — the ± exists because auto_tag heuristics
   have ~2-row rebuild jitter), `check_row_count.py`,
   `check_article_guardrails.py`, plus any round-specific invariant check
   (pattern: `check_band_label_invariants.py`).
4. Regenerate `audit/article/fact_sheet.md`
   (`scripts/build_article_factsheet.py` — preserves hand-authored §7) and
   re-pin any hardcoded dashboard copy (see the `publish-and-repin` skill).
5. `AUDIT_GATE.md` (or the round's ADJUDICATION.md) records the final
   verdict counts and gate status.
6. One-shot helper scripts that will never run again → `scripts/archive/`
   with a line in its README.
